# UNBRANDING 10 Per Brand Sample

Balanced sample created from the public Hugging Face dataset:

- Dataset: `MalarzDawid/UNBRANDING`
- Source file: `unbranding_v1.csv`
- Source URL: https://huggingface.co/datasets/MalarzDawid/UNBRANDING
- License: `cc-by-4.0`

Sampling rule:

- 12 brands
- 10 prompts per brand
- 5 `biased` prompts and 5 `directed` prompts per brand
- 120 total rows

The sample is stored in framework-ready CSV format:

```csv
id,prompt,target_concept,category,prompt_set,seed,source_filename
```
