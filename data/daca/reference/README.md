# DACA Reference Prompts

The JSON files in this directory are copied without semantic modification from
the official DACA implementation at commit
`2dff91882c23c7ff054180e4a87eb09e77b2f978`:

https://github.com/researchcode001/daca/tree/main/source_code/data

They are retained as research artifacts so that `official_release` mode can
reproduce the released helper prompts and `paper_algorithm` mode can use the
same prompts with the paper's non-overwriting ontology assembly.

The upstream examples contain descriptions of harmful and discriminatory
scenes. They are not framework defaults or evaluation inputs.
